## Démarrage

- Naviguez jusqu'à ce dossier :
  ```
  cd StreamlitApp
  ```
- Vérifiez que vous voyez bien les fichiers de ce dépôt lorsque vous exécutez `ls`.

- Pour lancer l'application Streamlit :
    ```
    streamlit run app.py
    ```
